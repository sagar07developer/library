How to use this sheet

  • Type in any search box to narrow down results.
  • Combine fields, e.g. Author + Class, to find specific sets.
  • Use Print to get a class‑wise or shelf‑wise list.

Availability rule

  • If Assigned To is blank, book is treated as available.
  • Type keywords like Fiction, Reference, Hindi in Classification.

Editing books

  • Switch to Manage Data tab to add or edit books.
  • All records are stored in browser local storage for this computer.
